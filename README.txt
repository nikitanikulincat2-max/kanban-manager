KanBan
Веб-приложение для командной работы над задачами по методологии Kanban.
Позволяет вести несколько досок, распределять задачи между исполнителями,
ограничивать видимость отдельных задач и следить за историей изменений.
Проект создан как учебная работа по дисциплине «Веб-дизайн и разработка».
Работает в браузере, устанавливается как приложение на телефон (PWA).

В командах часто теряются задачи: одни в мессенджере, другие в блокноте,
третьи — в голове у одного человека. В итоге никто не понимает,
кто чем занят и что уже сделано.
KanBan решает эту проблему: собирает все задачи в одном месте,
показывает их на доске и позволяет ограничивать доступ — часть задач
видят все, часть — только выбранные люди.

Что можно делать
Регистрироваться и входить в систему.
Создавать рабочие пространства (например, «Универ», «Работа»).
Внутри пространства создавать несколько досок.
На каждой доске — колонки: «К выполнению», «В работе», «Готово».
Создавать задачи: с описанием, приоритетом, сроком, исполнителем.
Перетаскивать задачи между колонками мышкой или кнопками.
Прикреплять файлы (PDF, PNG, JPG, ZIP, DOC, XLS) и оставлять комментарии.
Управлять видимостью задачи: для всех / только для себя / для группы / для выбранных пользователей.
Создавать группы и добавлять туда участников.
Приглашать людей в пространство и менять их роли.
Смотреть статистику по задачам на дашборде.
Инструкция для пользователя

Регистрация
Откройте сайт.
Нажмите «Зарегистрироваться».
Введите логин, email и пароль.
После регистрации войдите под своими данными.

Создание рабочего пространства
Пространство — это отдельный «кабинет» для команды или проекта.
На главной странице введите название в поле «Название нового пространства».
Нажмите «Создать».
Вы автоматически становитесь менеджером этого пространства.

Создание доски
Откройте пространство.
Введите название доски (например, «Разработка»).
Нажмите «Создать доску».
Доска появится с тремя готовыми колонками: К выполнению, В работе, Готово.

Создание задачи
Откройте доску.
В нужной колонке нажмите «+ Задача».
Заполните поля:
Заголовок — коротко, что нужно сделать.
Описание — подробности.
Приортет — низкий / средний / высокий.
Срок — дата, до которой нужно выполнить.
Исполнитель — кто будет делать.
Видимость — кто увидит задачу (см. ниже).
Нажмите «Создать задачу».

Как работает видимость задач
Режим	Кто видит задачу
🌐 Публичная	Все участники пространства
🔒 Приватная	Только автор и назначенный исполнитель
👤 Выбранные пользователи	Только те, кого вы отметите галочками
👥 Группа	Только участники выбранной группы
Автор задачи всегда видит её, независимо от режима.

Перемещение задач
Есть два способа:

Перетаскиванием — зажмите карточку и перетащите в другую колонку.
Кнопками — наведите на карточку, появятся кнопки «← Назад» и «Вперёд →».
Перемещать задачу может только менеджер пространства или автор задачи.

Редактирование задачи
Откройте задачу, кликнув по её названию.
Нажмите «✏️ Редактировать».
Поменяйте нужные поля.
Нажмите «Сохранить».
Комментарии и файлы
На странице задачи есть поле для комментария.
Кнопка «+ Загрузить файл» прикрепляет документы и изображения (до 10 МБ).
Все комментарии и файлы видны только тем, кто видит саму задачу.

Группы
Откройте пространство.
Нажмите «👥 Группы».
Создайте группу (например, «Backend-команда»).
Добавьте в неё участников.
Теперь при создании задачи можно выбрать видимость «Группа» и указать эту группу.
Приглашение участников
В пространстве нажмите «👥 Участники».
Введите логин или email человека.
Выберите роль: Участник или Менеджер.
Нажмите «Пригласить».

Роли
Участник — создаёт задачи, комментирует, перемещает свои задачи.
Менеджер — управляет пространством, досками, колонками, участниками и удаляет задачи.
Администратор — имеет доступ в Django Admin и полный контроль над системой.

Дашборд
Раздел «Дашборд» показывает:
сколько всего задач;
сколько просрочено;
сколько задач с высоким приоритетом;
диаграмму распределения задач по колонкам и по приоритетам.

Технологии
Backend: Python 3.13, Django 4.2, Django REST Framework, SimpleJWT, django-cors-headers, django-filter, Gunicorn, WhiteNoise
Frontend: React 18, TypeScript, Vite, React Router, Axios, Bootstrap 5, Chart.js, @hello-pangea/dnd, react-toastify
База данных: SQLite (для разработки), PostgreSQL (в production)
Развёртывание: GitHub, Vercel (frontend), Railway (backend + БД)
